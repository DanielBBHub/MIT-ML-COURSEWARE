MIT — Introduction to Artificial Intelligence

Repositorio de apuntes y ejercicios del curso MIT — Introduction to Artificial Intelligence, organizado por problem sets.
Estructura

Cada carpeta de problem_set_X contiene un README.md con los apuntes mínimos necesarios para entender y resolver los ejercicios de ese lab.

    problem_set_0/ — Python programming, symbolic algebra
    problem_set_1/ — Forward chaining, backward chaining, goal trees
    problem_set_2/ — Search, heuristics, optimal search, graph heuristics
    problem_set_3/ — Game search
    problem_set_4/ — CSP, k-nearest neighbors, decision trees
    problem_set_5/ — Neural nets, boosting

Objetivo

La idea de este repositorio es centralizar los apuntes del curso y separarlos por bloques temáticos para que cada problem set tenga solo la información realmente útil para:

    comprender los conceptos necesarios,
    preparar la resolución de los ejercicios,
    y repasar rápidamente antes de entregar el lab.

Cómo usar este repositorio

    Abre el README.md del problem set que estés trabajando.
    Revisa los conceptos teóricos asociados.
    Usa los ejemplos y definiciones como apoyo para resolver los ejercicios.
    Si necesitas contexto más amplio, consulta los demás módulos del curso.

Temas cubiertos

A lo largo del curso aparecen, entre otros, estos temas:

    razonamiento simbólico
    goal trees
    sistemas basados en reglas
    búsqueda informada y no informada
    game search
    restricciones y propagación de dominios
    clasificación con k-NN y árboles de decisión
    redes neuronales
    boosting

Nota sobre la organización

Este repositorio no intenta ser un volcado literal de apuntes, sino una versión reorganizada y enfocada en los contenidos útiles para cada práctica.
