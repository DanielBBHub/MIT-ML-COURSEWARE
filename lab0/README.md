## 2. Symbolic algebra

### Idea general

El álgebra simbólica consiste en representar expresiones matemáticas como estructuras manipulables por programa, en lugar de calcular directamente un valor numérico.

Por ejemplo, en vez de evaluar una expresión, el programa puede:

- construirla,
- simplificarla,
- derivarla,
- o transformarla.

### Representación de expresiones

Las expresiones suelen modelarse como árboles:

- nodos internos: operadores
- hojas: variables o constantes

Ejemplo conceptual:

- $\large x + 3$
- $\large x * (y + 2)$
- $\large sin(x)$

### Operaciones típicas

En este contexto suelen aparecer tareas como:

- construir expresiones simbólicas,
- evaluar expresiones con valores concretos,
- simplificar expresiones,
- derivar expresiones de forma simbólica.

### Qué conviene recordar

- una expresión simbólica no es un número,
- una operación simbólica transforma otra expresión,
- el objetivo es preservar la estructura matemática mientras se manipula.
